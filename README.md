# Praharshitha Kota

Healthcare IT and data analytics. I trained as a perfusion technologist, spent over a year in the cardiac operating theatres of KIMS Sunshine and KIMS Hospitals, and worked on Hospital Information System (HIS) customization as a product intern at KareXpert Technologies. I'm now doing a PGDM in AI and Data Science in Healthcare at IIHMR Bangalore.

The projects here are me taking a question from raw data to something a clinician or a manager can read: a perfusion app built from my own clinical work, survival models, dashboards, and small apps with a tested deployment pipeline behind them.

## Projects

| Project | What it does | Built with |
|---|---|---|
| [WholePerf](https://github.com/praharshitha-ai/wholeperf) | Web app for cardiac perfusion teams: BSA, blood flow, heparin and cannula calculators, per-patient procedure logs and disposables inventory, with Firestore rules that keep each clinician's records private. [Live demo](https://wholeperf.netlify.app) | React, TypeScript, Firebase |
| [Chlorhexidine trial: survival analysis](https://github.com/praharshitha-ai/chlorhexidine-vap-survival-analysis) | Time to ventilator-associated pneumonia (VAP) across two trial arms. 103 patients and 8 events, analysed with Kaplan-Meier curves, a log-rank test (p = 0.20) and a Cox model adjusted for age, APACHE II score and gender. | Python, pandas, lifelines |
| [Heart attack risk dashboard](https://github.com/praharshitha-ai/heart-attack-risk-tableau) | Tableau workbook with 18 worksheets, 2 dashboards and a story on demographic, lifestyle and regional risk factors. Exploratory, not a clinical tool. | Tableau |
| [Sentiment analysis dashboard](https://github.com/praharshitha-ai/Sentiment-Analysis) | Classifies text as positive, neutral or negative (Naive Bayes, logistic regression, SVM on TF-IDF features), with a Streamlit app for typed text or CSV uploads. [Demo video](https://youtu.be/Zb4HXzh-gXI) | Python, scikit-learn, Streamlit |
| [FastAPI CI/CD pipeline](https://github.com/praharshitha-ai/fastapi-cicd-render) | A prediction API whose tests run in GitHub Actions on every push and, when they pass, trigger a deploy to Render. | FastAPI, pytest, GitHub Actions, Render |
| [Employee attrition (in progress)](https://github.com/praharshitha-ai/employee-attrition-mlops-system) | Random Forest pipeline on HR data with a Streamlit front end, a FastAPI service and CI. The prediction endpoint is still being built. | scikit-learn, FastAPI, Docker |
| [Crypto trader behaviour vs market sentiment](https://github.com/praharshitha-ai/crypto-trader-sentiment-analysis) | Joins a fear/greed sentiment index with trade records to compare position size and profit across sentiment phases. | Python, pandas, seaborn |
